一、项目背景

作为一名即将升入本科的软件工程学生，我希望通过一个完整的博客项目，把学过的 Spring、Vue、MySQL 串联起来，走一遍从设计到上线的工程流程。

本文以「前后端分离」为核心架构，后端提供 REST 接口，前端负责展示与交互。

二、技术选型

后端采用 Spring Boot 3.2 + MyBatis-Plus，前端使用 Vue3 + Element Plus，数据库为 MySQL 8。选择这套组合的原因是学习成本可控、生态成熟。

三、核心代码示例

@RestController
@RequestMapping("/api/articles")
public class ArticleController {
    @GetMapping("/{id}")
    public Result<ArticleVO> detail(@PathVariable Long id) {
        return Result.success(articleService.getDetail(id));
    }
}

四、部署上线

最终通过 Nginx 反向代理，将前端静态资源与后端接口统一在同一域名下，并配置 HTTPS 证书完成上线。
